# HerbTrust Dashboard

This is a React.js dashboard project for a blockchain-based traceability system of Ayurvedic herbs.

## Features
- Sidebar navigation with different modules
- Dashboard overview with key stats
- Recent supply chain events with geo-tagging
- Blockchain network status panel
- Modern UI with animations and responsive layout

## How to run
1. Install dependencies:
   ```bash
   npm install
   npm install react-icons
   ```
2. Start the project:
   ```bash
   npm start
   ```
3. The app will open at `http://localhost:3000`.

## Future Improvements
- Add routing using react-router
- Connect with blockchain API or smart contracts
- Implement authentication
- Add dark mode toggle
